# nope-redis

Simple & Fast Node.js in-memory caching — Redis-like functionality without a Redis server.

- 🚀 **Fast**: 1M+ SET, 2M+ GET ops/sec with a flat heap under sustained load
- ⏰ **TTL**: automatic key expiration with eager cleanup on read
- 🔄 **Eviction**: LRU, LFU and TTL policies with a configurable memory limit (MB)
- 🎯 **Batch operations**, 📈 **statistics**, 🛡️ **self-recovery**, 📘 **TypeScript types**
- 🔧 **Zero runtime dependencies** — single file, Node.js ≥ 12

## Install

```bash
npm install nope-redis
```

## Quick Start

```javascript
const nopeRedis = require('nope-redis');

nopeRedis.setItem('user:1', { name: 'John', age: 30 }, 10); // TTL: 10s
const user = nopeRedis.getItem('user:1'); // { name: 'John', age: 30 } — null if missing/expired
nopeRedis.deleteItem('user:1');

// Optional runtime configuration
nopeRedis.config({ defaultTtl: 60, maxMemorySize: 100, evictionPolicy: 'lru' });
```

TypeScript definitions are included (`setItem<T>`, `getItem<T>`, …).

## API at a Glance

| Function | Description | Returns |
|----------|-------------|---------|
| `setItem(key, value, ttl?)` | Store any JS value (default TTL: 30s) | `boolean` |
| `getItem(key)` | Read a value | `T \| null \| false` |
| `deleteItem(key)` | Remove a key | `boolean` |
| `itemStats(key)` | Per-key `expires_at`, `remaining_seconds`, `hit` | `ItemStats \| null \| false` |
| `setItems(items)` | Bulk set `[{ key, value, ttl? }]` | `boolean[] \| false` |
| `getItems(keys)` | Bulk read | `Record<string, T \| null> \| false` |
| `deleteItems(keys)` | Bulk remove | `boolean` |
| `stats(options?)` | Cache-wide statistics (`showSize` for memory usage) | `Stats \| false` |
| `config(options)` | `defaultTtl`, `maxMemorySize` (MB), `evictionPolicy`, `maxChecksPerCycle`, `isMemoryStatsEnabled` | `boolean` |
| `flushAll()` | Clear all data, keep service running | `boolean` |
| `SERVICE_KILL()` / `SERVICE_START()` | Stop / restart the background service | `Promise<boolean>` |

All functions return `false` when the service is stopped. Full reference with examples: [docs/README.md](https://github.com/orhanayd/no-redis/blob/main/docs/README.md#api-reference).
